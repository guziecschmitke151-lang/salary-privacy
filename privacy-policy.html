Политика конфиденциальности Приложение: Сдельщик — калькулятор зарплаты Последнее обновление: 1 июля 2026 г. Настоящая Политика конфиденциальности описывает, как приложение «Сдельщик — калькулятор зарплаты» (далее — Приложение) обрабатывает данные пользователей. 1. Какие данные мы собираем Приложение не собирает и не передаёт на сервер никакие персональные данные пользователя. Все данные (прайс-лист, история расчётов) хранятся исключительно на устройстве пользователя в локальной памяти (localStorage) и не покидают устройство. 2. Реклама Приложение использует рекламную платформу Google AdMob для показа рекламных объявлений. AdMob может собирать следующие данные в соответствии со своей политикой конфиденциальности: Рекламный идентификатор устройства (Advertising ID) Приблизительное местоположение (на уровне страны/региона) Информация об устройстве (модель, версия Android) Данные о взаимодействии с рекламой Эти данные используются исключительно для показа релевантной рекламы. Ознакомиться с политикой конфиденциальности Google можно по адресу: policies.google.com/privacy 3. Покупки внутри приложения Приложение предоставляет возможность совершить разовую покупку для отключения рекламы. Обработка платежей осуществляется через RuStore и/или Google Play. Платёжные данные не обрабатываются и не хранятся Приложением напрямую. 4. Разрешения Приложение запрашивает следующие разрешения: INTERNET — для показа рекламных объявлений ACCESS_NETWORK_STATE — для проверки наличия интернета перед загрузкой рекламы Приложение не запрашивает доступ к камере, микрофону, контактам, файлам или геолокации. 5. Дети Приложение не предназначено для детей младше 13 лет. Мы намеренно не собираем данные несовершеннолетних. 6. Изменения политики Мы можем обновлять настоящую Политику конфиденциальности. Актуальная версия всегда доступна по данному адресу. Продолжение использования Приложения означает согласие с обновлённой политикой. 7. Контакты По вопросам, связанным с конфиденциальностью, вы можете связаться с нами по электронной почте. Адрес электронной почты укажи свой при публикации. © 2026 Сдельщик — калькулятор зарплаты.
